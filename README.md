# memory-game-colorman
🎮 ColorMan – Memory Sequence Game

ColorMan is a browser-based short-term memory game where players must remember and repeat an increasing sequence of colors generated by the system.

The difficulty increases with each level, making it a fun logic and concentration challenge.

🧠 Game Objective

Train memory and focus by correctly repeating a sequence of colors.

Each successful round unlocks the next level with a longer color pattern.

🎯 Rules of the Game

The player begins by selecting an initial color.

The system generates an additional color.

The player must repeat:

their selected color

the system-generated color

On each level:

a new color is added to the sequence

the player must repeat the full pattern correctly.

If the sequence is incorrect:

the game resets

the player must restart from level 1.
